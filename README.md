# CS345_Assignment1
First assignment for my CS345 Game Dev Class

In Tutorial 1, we covered “Tilted Table” game/simulation where a ball rolls on a table without friction that the player can rotate in x and z axis.
In Assignment 1, you need to extend this into a single level game, by making significant changes to the game. Below are required specifications:
Check the rubric for more specific grading specifications. 

    Make significant changes to the game logic (25 points)
        To give you some ideas:
            Adding enemies trying to knock the ball off the table?
            Allowing the ball to destroy obstacles/enemies?
            Multiple tables that are located separately, and player controls the table that the ball touches?
            Adding elevators/portals to transfer ball from one location to another? etc.
    Make it a game which has a goal. (25 points)
        To give you some ideas:
            Collecting a certain number of gold coins?
            Reaching a certain destination?
            Advancing through multiple levels? etc.
    Make sure that the game is challenging and fun to play (20 points)
    Add a simple GUI. (20 points)
        To give you some ideas as potential extensions:
            keep a counter for highest score?
            keep a leaderboard?
            make a pause screen/game over screen/intro screen etc. (you will need to Google GUI in Unity for this part)
    Have a complete game loop. (10 points)
        That is to say, the game should have an end, and should have a replay and pause option.
